# elena-paspel.github.io

Personal research portfolio of **Elena Paspel**, independent researcher in evidence-informed adult education, AI and digital literacy, and digital health communication.

**Live site:** https://elena-paspel.github.io/

- ORCID: https://orcid.org/0009-0008-9306-7058
- Featured project: [Personal AI Mentor](https://github.com/elena-paspel/personal-ai-mentor)

## What's in this repository

| File | Purpose |
|---|---|
| `index.html` | The whole website: content, styles and animations in one file |
| `assets/elena-paspel.webp` | Portrait |
| `assets/ep-logo.webp` / `ep-logo-still.png` | Animated and still "ep" logo (Eruditio et Potentia) |
| `assets/workshop-feedback.mp4` + `-poster.jpg` | Workshop feedback video (participant names and photos covered) |
| `.nojekyll` | Tells GitHub Pages to serve the files as they are |

## Editing

All text lives in `index.html`. On GitHub, open the file, click the pencil icon, edit, then **Commit changes**. The live site updates within a minute or two.
